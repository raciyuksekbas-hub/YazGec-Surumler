Bu depo yalnızca **YazGeç**'in yayımlanmış sürümlerini barındırır; kaynak kod burada değildir.

* **Son sürüm:** [Releases](https://github.com/raciyuksekbas-hub/YazGec-Surumler/releases/latest)
